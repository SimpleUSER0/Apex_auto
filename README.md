# APEX AUTO DETAILING

ქართულენოვანი, ერთგვერდიანი პორტფოლიოს დემო პრემიუმ ავტოდეტეილინგის ბიზნესისთვის. გამოიყენება მხოლოდ HTML, CSS და Vanilla JavaScript — framework, build ან სერვერული ნაწილი არ სჭირდება.

## დემოს განმარტება

APEX AUTO DETAILING გამოგონილი ბიზნესია. ეს პროექტი რეალურ მისამართს, ტელეფონს, სოციალურ ანგარიშს ან სამუშაო საათებს არ წარმოაჩენს. შესაბამის ადგილებში მითითებულია „დასაზუსტებელია“. მომსახურებები და ბრენდის ტექსტი დემო კონცეფციის ნაწილია. ფასები არ არის გამოგონილი — მითითებულია „ფასი შეთანხმებით“.

ფოტოები არის საილუსტრაციო საფონდო მასალა. ისინი APEX-ის ნამუშევრები ან თანამშრომლები არ არის. წყაროები, ავტორები და ლიცენზიები იხილე CREDITS.md-ში.

Before / After ბლოკი ერთი ფოტოს ორი ვიზუალური მდგომარეობის დემოა: „მანამდე“ მხარეს აქვს CSS ეფექტი. რეალურ სამუშაოს შედეგს არ ასახავს და ეს განმარტება საიტზეც ჩანს. რეალური ბიზნესისთვის შეცვალე ერთი და იმავე ავტომობილის იმავე რაკურსით გადაღებული ნამდვილი ფოტოებით.

## ფაილები

- index.html — მთავარი გვერდი root-ში.
- css/style.css — დიზაინი, მობილური განლაგება და მოძრაობის პარამეტრები.
- js/script.js — მენიუ, შედარების სამართავი, დემო ჯავშანი და გალერეა.
- assets/images/ — ადგილობრივი ოპტიმიზებული WebP ფოტოები.
- assets/fonts/ — ქართული Noto Sans Georgian ფონტი და ლიცენზია.
- CREDITS.md — ფოტოების და ფონტის წყაროები.
- QA.md — დასრულებული შემოწმების შედეგები.
- .nojekyll — GitHub Pages-ზე სტატიკური ფაილების პირდაპირ გამოსაქვეყნებლად.

## გაშვება ლოკალურად

გაშალე არქივი და გახსენი index.html ბრაუზერში. ადგილობრივი ფოტოები, ფონტი და ყველა ძირითადი ფუნქცია პირდაპირ გახსნისასაც მუშაობს.

ან პროექტის საქაღალდეში გაუშვი:

```bash
python3 -m http.server 8000
```

გახსენი http://localhost:8000. სერვერის შესაჩერებლად გამოიყენე Ctrl+C.

## GitHub Pages-ზე გამოქვეყნება

1. შექმენი GitHub რეპოზიტორია.
2. ატვირთე არქივის შიგთავსი რეპოზიტორიის root-ში. index.html არ უნდა აღმოჩნდეს დამატებით შიდა საქაღალდეში.
3. გახსენი Settings → Pages.
4. Source: Deploy from a branch.
5. აირჩიე main და / (root), შემდეგ Save.
6. გამოქვეყნების დასრულების შემდეგ გახსენი GitHub-ის მიერ ნაჩვენები ბმული.

ყველა ბილიკი ფარდობითია. პროექტი რეპოზიტორიის ქვე-ბილიკზეც მუშაობს. npm და build საჭირო არ არის. ამ დავალებაში რეალურ ანგარიშზე გამოქვეყნება არ შესრულებულა.

## ფუნქციები

- Sticky ნავიგაცია და მობილური მენიუ.
- კლავიატურით სამართავი Before / After range slider.
- მომსახურებიდან წინასწარ შერჩეული დემო ჯავშანი.
- სახელის, ტელეფონის, სერვისისა და თარიღის ქართული ვალიდაცია.
- სასურველი თარიღი არ უნდა იყოს წარსულში; მიმდინარე დღე გამოითვლება თბილისის დროით.
- Submit აჩვენებს: „გმადლობთ! ეს არის დემო ჯავშნის ფორმა. მოთხოვნა არ გაგზავნილა და ვიზიტი არ დაჯავშნილა.“
- არც მონაცემები იგზავნება და არც ჯავშანი კეთდება. მონაცემები იწმინდება დასრულებისა და ფანჯრის დახურვისას.
- WhatsApp, დარეკვა, რუკა და სოციალური ღილაკები განმარტების დიალოგებს ხსნის — არ აქვთ გამოგონილი ბმულები.
- გალერეის გადიდება, ისრები, კლავიატურა, გადაფურცვლა და ფოკუსის დაბრუნება.
- შემცირებული მოძრაობის მხარდაჭერა, lazy-loaded ფოტოები, ქართული SEO და Open Graph ტექსტები.
- მესამე მხარის მოთხოვნები, ანალიტიკა, cookies და მონაცემთა შენახვა არ გამოიყენება.

## რეალური ბიზნესისთვის მოსამზადებლად

- ჩაანაცვლე დასაზუსტებელი მონაცემები მფლობელის ოფიციალური ტელეფონით, მისამართით, საათებით და სოციალური ბმულებით.
- data-placeholder ღილაკები შეცვალე ნამდვილი tel:, wa.me, Maps და ოფიციალური სოციალური გვერდების ბმულებით; თუ ნომერი მხოლოდ ტელეფონია, WhatsApp ცალკე დაადასტურე.
- ჩაანაცვლე ფოტოები საკუთარი ნამუშევრებით; განაახლე ალტერნატიული ტექსტებიც.
- დაამტკიცე მომსახურებები, აღწერები და ფასის პირობები.
- რეალური ჯავშნისთვის საჭიროა ცალკე დამუშავების არხი. ახლანდელი ფორმა მხოლოდ ადგილობრივი დემოა.
- საბოლოო დომენის დადასტურების შემდეგ დაამატე canonical, og:url და საჭიროების შემთხვევაში აბსოლუტური og:image URL.
- დემოს robots მნიშვნელობაა noindex,nofollow. ოფიციალური საიტის დამტკიცების შემდეგ შეცვალე ინდექსაციის პოლიტიკა.
